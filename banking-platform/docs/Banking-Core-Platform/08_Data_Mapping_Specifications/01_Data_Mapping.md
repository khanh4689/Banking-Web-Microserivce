```
        ▼
┌───────────────────┐

│                   │  Routes by path prefix
│  /auth/**  ──────►│──────────────────────► auth-service :8082

│  /accounts/**    ►│──────────────────────► account-service :8083

└───────────────────┘
        │
        │ Internal network only (not via Gateway)
        ▼
┌──────────────────────────────────────────────────────────────────┐

└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│  auth-service ──[Kafka user-events]──► user-service              │
│                                   └──► account-service           │
└──────────────────────────────────────────────────────────────────┘
```

### 1.2 Column Legend

| Column | Description |
|--------|-------------|
| Source Field | Field name in the source system/payload |
| Target Field | Field name in the target system/payload |
| Data Type | Data type in the target |
| Transformation Logic | How the value is derived or transformed |
| Validation Logic | Rules applied before mapping |
| Mandatory | Whether field is required in the target |
| Error Handling | What happens when mapping or validation fails |

### 1.3 Transformation Codes

| Code | Description |
|------|-------------|
| DIRECT | Value copied without transformation |
| HASH | Value hashed (BCrypt or SHA-256) |
| GENERATE | Value generated by system (not from source) |
| DEFAULT | System-assigned default if not provided |
| DERIVE | Derived from another field or JWT claim |
| TRUNCATE | Value truncated to fit target length |
| ROUND | Numerical rounding applied |
| OMIT | Field not included in target payload |

## DM-001 Mobile/Web Client → API Gateway → auth-service (Registration)

**Trigger:** Customer submits registration form  
**Source:** Mobile/Web Client  
**Target:** auth-service — POST /auth/register  
**Method:** HTTP POST  
**Auth:** None (public endpoint)  

### Request Mapping

| Source Field | Target Field | Data Type | Mandatory | Transformation Logic | Validation Logic | Error Handling |
|-------------|-------------|-----------|-----------|---------------------|-----------------|----------------|
| form.username | body.username | String | Yes | DIRECT | 3–50 chars; alphanumeric; not null | VAL-REG-002: HTTP 400 "Username must be 3–50 characters" |
| form.email | body.email | String | Yes | DIRECT; lowercase trim | Valid email format (RFC 5322); not null | VAL-REG-006: HTTP 400 "Invalid email address" |
| form.password | body.password | String | Yes | DIRECT (never logged) | Min 8 chars; uppercase; lowercase; digit | VAL-REG-009: HTTP 400 "Password does not meet requirements" |

### Internal Mapping (auth-service — Client → Database)

| Source Field | Target Field (auth_db.users) | Data Type | Transformation Logic | Validation Logic | Error Handling |
|-------------|------------------------------|-----------|---------------------|-----------------|----------------|
| body.username | users.username | VARCHAR(50) | DIRECT | UNIQUE check: SELECT 1 FROM users WHERE username = ? | DUPLICATE_USERNAME: HTTP 409 |
| body.email | users.email | VARCHAR(255) | DIRECT; toLowercase() | UNIQUE check: SELECT 1 FROM users WHERE email = ? | DUPLICATE_EMAIL: HTTP 409 |
| body.password | users.password_hash | VARCHAR(255) | HASH: BCryptPasswordEncoder.encode(password) — work factor 10 | N/A after hash | If BCrypt fails: HTTP 500 |
| GENERATE | users.id | VARCHAR(36) | UUID.randomUUID().toString() | Must be globally unique | Collision: retry |
| DEFAULT | users.role | VARCHAR(20) | "ROLE_USER" | Fixed constant | N/A |
| DEFAULT | users.enabled | BOOLEAN | false | Fixed default | N/A |
| DEFAULT | users.email_verified | BOOLEAN | false | Fixed default | N/A |
| GENERATE | users.created_at | TIMESTAMP | NOW() UTC | N/A | N/A |

### Email Verification Token Mapping

| Source | Target Field (auth_db.email_verification_tokens) | Data Type | Transformation Logic | Validation |
|--------|--------------------------------------------------|-----------|---------------------|------------|
| GENERATE | token | VARCHAR(255) | UUID.randomUUID().toString() | UNIQUE constraint |
| users.id | user_id | VARCHAR(36) | DIRECT | FK to users.id |
| GENERATE | expires_at | TIMESTAMP | NOW() + 24 hours | Must be future |
| DEFAULT | used | BOOLEAN | false | Fixed |

### Response Mapping (auth-service → Client)

| Source | Response Field | Transformation | Notes |
|--------|---------------|----------------|-------|
| STATIC | success | true | Always true on HTTP 200 |
| STATIC | message | "User registered successfully. Please verify your email." | |
| OMIT | userId | — | Not included for security |
| OMIT | password_hash | — | NEVER included in response |

## DM-002 Mobile/Web Client → API Gateway → auth-service (Login)

**Trigger:** Customer submits login form  
**Source:** Mobile/Web Client  
**Target:** auth-service — POST /auth/login  
**Method:** HTTP POST  
**Auth:** None (public endpoint)

### Request Mapping

| Source Field | Target Field | Data Type | Mandatory | Transformation | Validation | Error Handling |
|-------------|-------------|-----------|-----------|----------------|------------|----------------|
| form.username | body.username | String | Yes | DIRECT | Non-empty | HTTP 400 "Username is required" |
| form.password | body.password | String | Yes | DIRECT (never logged) | Non-empty | HTTP 400 "Password is required" |

### Internal Processing Mapping

| Process Step | Source | Target | Transformation | Error Handling |
|-------------|--------|--------|----------------|----------------|
| User lookup | body.username | auth_db.users.username | SELECT * FROM users WHERE username = ? | Not found: HTTP 401 "Invalid credentials" |
| Password verify | body.password + users.password_hash | boolean | BCryptPasswordEncoder.matches(raw, hash) | Mismatch: HTTP 401 "Invalid credentials" |
| Email check | users.email_verified | Check boolean | Must be true | false: HTTP 401 "Email not verified" |
| Enabled check | users.enabled | Check boolean | Must be true | false: HTTP 401 "Account is disabled" |

### JWT Generation Mapping

| Source | JWT Claim | Type | Transformation |
|--------|-----------|------|----------------|
| users.id | sub | String | DIRECT — userId as JWT subject |
| users.username | username | String | DIRECT |
| users.role | roles | List\<String\> | Arrays.asList(user.getRole()) |
| GENERATE | iat | Long | System.currentTimeMillis() / 1000 |
| GENERATE | exp | Long | iat + (expirationMinutes × 60) = iat + 600 |

### Refresh Token Generation Mapping

| Source | Target Field (auth_db.refresh_tokens) | Transformation |
|--------|---------------------------------------|----------------|
| GENERATE | raw_token (returned to client) | UUID.randomUUID() + additional entropy |
| raw_token | token_hash | SHA-256(raw_token) — stored in DB |
| users.id | user_id | DIRECT |
| GENERATE | expires_at | NOW() + 7 days |
| DEFAULT | revoked | false |

### Response Mapping (auth-service → Client)

| Source | Response Field | Data Type | Transformation | Notes |
|--------|---------------|-----------|----------------|-------|
| JwtUtil.generateToken() | accessToken | String | DIRECT | RS256 signed JWT |
| raw_refresh_token | refreshToken | String | DIRECT | Raw token (not hash) |
| jwtProperties.expirationMinutes × 60 | expiresIn | Long | Minutes to seconds: × 60 | In seconds |
| OMIT | password_hash | — | — | NEVER returned |
| OMIT | token_hash | — | — | NEVER returned |

## DM-003 auth-service → Kafka → user-service (Profile Provisioning)

**Trigger:** UserCreatedEvent published to Kafka after registration transaction commits  
**Producer:** auth-service (AuthKafkaProducer)  
**Topic:** user-events  
**Consumer:** user-service (UserKafkaConsumer — group: user-service-group)  
**Serialisation:** JSON  
**Key:** event.id (userId string) — ensures ordering per user  

### Kafka Event Mapping (auth-service → UserCreatedEvent)

| Source Field (auth_db.users) | Kafka Event Field | Data Type | Transformation | Notes |
|-----------------------------|-------------------|-----------|----------------|-------|
| users.id | id | String | DIRECT | auth-service userId; becomes auth_id in user-service |
| users.email | email | String | DIRECT | Customer email |
| users.username | username | String | DIRECT | Customer username |

### Consumer Mapping (UserCreatedEvent → user_db.users_profile)

| Source (Event Field) | Target Field (users_profile) | Data Type | Transformation | Mandatory | Error Handling |
|---------------------|------------------------------|-----------|----------------|-----------|----------------|
| event.id | auth_id | VARCHAR(36) | DIRECT | Yes | Duplicate auth_id: DuplicateUserException — skip (idempotent) |
| event.email | email | VARCHAR(255) | DIRECT | Yes | Null email: log error, skip event |
| event.username | username | VARCHAR(50) | DIRECT; truncate to 50 if > 50 | No | TRUNCATE applied |
| GENERATE | id | UUID | UUID.randomUUID() | Yes | Collision extremely unlikely; UUID v4 |
| DEFAULT | kyc_status | VARCHAR(20) | "PENDING" | Yes | Fixed default |
| GENERATE | created_at | TIMESTAMP | NOW() UTC | Yes | |
| GENERATE | updated_at | TIMESTAMP | NOW() UTC | Yes | |
| DEFAULT | full_name | VARCHAR(100) | null | No | Customer populates later |
| DEFAULT | phone | VARCHAR(20) | null | No | Customer populates later |
| DEFAULT | avatar | VARCHAR(500) | null | No | Customer populates later |

### Idempotency Handling

| Scenario | Detection | Action |
|----------|-----------|--------|
| Duplicate UserCreatedEvent | UNIQUE constraint on auth_id OR DuplicateUserException from service | Log WARN; return without processing; Kafka offset committed |
| event.id is null | Null check before DB insert | Log ERROR; skip; offset committed to prevent infinite retry |
| event.email is null | Null check | Log ERROR; skip; offset committed |
| DB unavailable | SQLException | Throw exception; Kafka retries with backoff |

## DM-004 auth-service → Kafka → account-service (Account Provisioning)

**Trigger:** Same UserCreatedEvent on user-events topic  
**Consumer:** account-service (UserCreatedEventConsumer — group: account-service-group)  
**Parallel to DM-003 (different consumer group)**

### Consumer Mapping (UserCreatedEvent → account_db.accounts)

| Source (Event Field) | Target Field (accounts) | Data Type | Transformation | Mandatory | Error Handling |
|---------------------|-------------------------|-----------|----------------|-----------|----------------|
| event.id | user_id | VARCHAR(36) | DIRECT | Yes | Null userId: log error, throw to trigger Kafka retry |
| GENERATE | id | UUID | UUID.randomUUID() | Yes | |
| GENERATE | account_number | VARCHAR(12) | Random 10-digit: format("%010d", random) — uniqueness loop | Yes | Collision: regenerate until unique |
| DEFAULT | balance | NUMERIC(19,2) | BigDecimal.ZERO.setScale(2) → 0.00 | Yes | |
| DEFAULT | currency | VARCHAR(3) | "VND" | Yes | |
| DEFAULT | status | VARCHAR(20) | AccountStatus.ACTIVE | Yes | |
| DEFAULT | version | BIGINT | 0 | Yes | JPA @Version seed |
| GENERATE | created_at | TIMESTAMP | NOW() UTC (Hibernate @CreationTimestamp) | Yes | |
| GENERATE | updated_at | TIMESTAMP | NOW() UTC (Hibernate @UpdateTimestamp) | Yes | |

### Idempotency Check

| Check | Query | Positive Result | Negative Result |
|-------|-------|-----------------|-----------------|
| Account exists for userId | `SELECT 1 FROM accounts WHERE user_id = ?` | Return existing AccountResponse; log WARN | Create new account |

### Error Escalation

| Error Type | Behaviour |
|------------|-----------|
| DB unavailable | Throw RuntimeException → Kafka retries |
| Account number collision | Regenerate with loop (max 10 attempts); then throw |
| Duplicate userId (idempotent) | Silently return existing account; commit Kafka offset |

## DM-008 transaction-service → account-service (Internal Debit/Credit)

**POST /internal/accounts/{accountNumber}/debit** (No JWT)  
**POST /internal/accounts/{accountNumber}/credit** (No JWT)  

### Debit Request Mapping

| Source | HTTP Field | Target | Transformation | Notes |
|--------|-----------|--------|----------------|-------|
| fromAccountNumber | path variable {accountNumber} | String | DIRECT | 10-digit account |
| request.amount (rounded) | body.amount | BigDecimal | DIRECT | Already rounded in transaction-service |

### account-service Internal Debit Processing

| Step | Source | Target | Transformation | Error |
|------|--------|--------|----------------|-------|
| Lock account | accountNumber | accounts row | SELECT FOR UPDATE (pessimistic lock) | Lock timeout: HTTP 500 |
| Validate status | accounts.status | check | Must be == ACTIVE | HTTP 400 "Account is not ACTIVE" |
| Validate balance | accounts.balance | check | balance >= amount | HTTP 400 "Insufficient balance" |
| Update balance | accounts.balance - amount | accounts.balance | balance.subtract(amount).setScale(2, HALF_UP) | DB constraint: balance ≥ 0 |
| Increment version | accounts.version | accounts.version | version + 1 (Hibernate auto) | OptimisticLockException on stale read |
| Update timestamp | NOW() | accounts.updated_at | Hibernate @UpdateTimestamp | |

### Debit Response Mapping

| Source | Response | Notes |
|--------|----------|-------|
| Success | HTTP 200, empty body | |
| Insufficient balance | HTTP 400 + message | transaction-service catches; marks TX FAILED |
| Account not found | HTTP 404 + message | transaction-service catches; marks TX FAILED |
| Service unavailable | ResourceAccessException | transaction-service returns HTTP 503 |

### Credit Request/Processing Mapping

| Step | Transformation | Difference from Debit |
|------|----------------|----------------------|
| Balance update | balance.add(amount).setScale(2, HALF_UP) | Add (not subtract) |
| Balance validation | None — credits always increase balance | No floor check needed |
| Status check | Same: must be ACTIVE | Same |
| Locking | Same: pessimistic write lock | Same |

## DM-010 Services → Notification Service (Email Events)

### Email Event Mapping

#### Event Type: REGISTRATION_VERIFICATION

| Source | Email Field | Transformation | Example Value |
|--------|------------|----------------|---------------|
| users.email | To | DIRECT | john@example.com |
| STATIC | From | Environment: SPRING_MAIL_USERNAME | noreply@bankingplatform.com |
| STATIC | Subject | Template | "Verify your Banking Core Platform account" |
| email_verification_tokens.token | Link parameter | URL encode | /auth/verify-email?token={token} |
| GENERATE | Body | Template render | "Click here to verify: {link}. Expires in 24 hours." |

#### Event Type: PASSWORD_RESET

| Source | Email Field | Transformation |
|--------|------------|----------------|
| users.email | To | DIRECT |
| password_reset_tokens.token | Link parameter | /auth/reset-password?token={token} |
| STATIC | Expiry note | "Link expires in 1 hour." |

#### Event Type: TRANSFER_CONFIRMATION

| Source | Email Field | Transformation |
|--------|------------|----------------|

| transactions.amount | Body | Formatted: ₫{amount} |
| transactions.to_account | Body | Destination account number |
| transactions.id | Body | Transaction reference |
| transactions.created_at | Body | Formatted datetime |

#### Event Type: ACCOUNT_FREEZE_NOTIFICATION

| Source | Email Field | Transformation | Compliance Note |
|--------|------------|----------------|-----------------|
| account owner email | To | Looked up via user-service | |
| STATIC | Subject | "Important: Your account has been restricted" | Do NOT include AML details |
| STATIC | Body | Template: contact bank guidance + reference number | AML Regulation: no investigation disclosure |
| freeze_reason.referenceNumber | Body | DIRECT | For customer to quote |

### SMTP Configuration Mapping

| Config Key | Source | Value |
|------------|--------|-------|
| spring.mail.host | Static | smtp.gmail.com |
| spring.mail.port | Static | 587 |
| spring.mail.username | Environment | SPRING_MAIL_USERNAME |
| spring.mail.password | Environment | SPRING_MAIL_PASSWORD |
| spring.mail.properties.mail.smtp.auth | Static | true |
| spring.mail.properties.mail.smtp.starttls.enable | Static | true |

### Email Delivery Error Handling

| Error Type | Behaviour | Retry |
|------------|-----------|-------|
| SMTP connection failed | Log ERROR; user creation still succeeds | Manual resend available via /auth/resend-verification-email |
| Invalid email address | Log WARN; skip email | N/A |
| Mail server rejects message | Log ERROR with recipient and error code | No automatic retry; operational alert |
| Email content render failure | Log ERROR; use fallback plain text | Immediate retry with plain text |
